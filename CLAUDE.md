# Pépite

Avant toute chose, lire `SUIVI.md` : il dit où en est le projet, ce qui reste à
faire et les habitudes de travail. Le mettre à jour à la fin de chaque étape
(section « Ce qui est fait », tableau Supabase, « Prochaines étapes »).

La personne qui porte le projet n'est pas développeuse : lui répondre en
français, simplement, et lui dire clairement quand elle doit faire quelque chose
elle-même (par exemple exécuter un fichier SQL dans Supabase).
